# Repository history

The MIT-era history is preserved in `maelys-dev/maelys-datalog-archive`, a private
repository. The transition already took place on 2026-09-03: the active public
`maelys-dev/maelys-datalog` repository starts with the MPL-2.0 line at
`v0.1.0-alpha.2`. Its `v0.1.0-alpha.3` release includes the WASM filter-link fix.

On 2026-09-05 the historical repository was put into GitHub's read-only archived
state. The open-core/module refactor starts from public commit
`c7cc4986db5363481505c7ced1ca5a6f7b8cebd7`; no second public repository or second
history reset is needed. Existing public tags and releases are retained.

The historical repository also contains the license-transition commit; it is
not exclusively an MIT snapshot. Files and revisions must be interpreted with
their applicable license. Archiving or starting a new repository does not revoke
permissions already granted for copies previously distributed under MIT.

The old repository is private. Users of earlier published copies retain their
rights, but this document does not promise public access to the private archive.
